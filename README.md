## 📁 Структура проекта

```bash
.
├── cmd/
│   ├── client/          # Точка входа клиента (TUI + CLI)
│   └── server/          # Точка входа сервера
├── internal/
│   ├── client/          # Клиентская бизнес-логика
│   ├── config/          # Конфигурация (env + viper)
│   ├── crypto/          # Шифрование данных
│   ├── grpc/            # gRPC-сервер и клиенты
│   ├── handler/         # Обработчики
│   ├── models/          # Общие модели и protobuf
│   ├── service/         # Бизнес-сервисы
│   ├── storage/         # PostgreSQL + миграции
│   ├── token/           # JWT-логика
│   └── tui/             # Терминальный интерфейс
├── proto/               # .proto файлы и сгенерированный код
├── migrations/          # Goose-миграции БД
├── pkg/                 # Переиспользуемые пакеты
├── .env.example
├── secret.example.json
├── go.mod
└── README.md
```

## 🚀 Быстрый старт

### 1. Клонирование и подготовка

```bash
git clone https://github.com/aga-absolut/Vault-System.git
cd Vault-System

# Настройка конфигурации
cp .env.example .env
cp secret.example.json secret.json
```

### 2. Запуск сервера

```bash
go run ./cmd/server/main.go -a :3200 -d "postgres://user:pass@localhost:5432/keeper?sslmode=disable"
```

### 3. Запуск клиента (TUI)

```bash
go run ./cmd/client/main.go
```

### 4. Сборка бинарников

```bash
# Сервер
go build -o bin/vault-server ./cmd/server

# Клиент
go build -o bin/vault-client ./cmd/client
```
