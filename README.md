Vault-System — Надёжный менеджер паролей

Клиент-серверная система для безопасного хранения приватных данных.  

Выпускной проект курса «Go-разработчик» (Яндекс.Практикум)

✨ Возможности

- Полноценная аутентификация: регистрация, логин, JWT-токены
- Четыре типа данных:
  - Пары логин/пароль
  - Произвольные текстовые заметки
  - Бинарные файлы (документы, фото и т.д.)
  - Данные банковских карт
- Метаинформация к каждой записи (теги, URL, комментарии, одноразовые коды и т.д.)
- Синхронизация в реальном времени между всеми устройствами пользователя
- Красивый терминальный интерфейс (TUI) на Bubble Tea + Lip Gloss
- gRP* + Protocol Buffers — быстрый бинарный протокол
- Шифрование данных на клиенте (AES-256-GCM) перед отправкой на сервер
- Кросс-платформенный CLI (Windows, Linux, macOS)
- Вывод версии и даты сборки бинарника

📁 Структура проекта
```bash
.
├── cmd/
│   ├── client/          # Точка входа клиента (TUI + CLI)
│   └── server/          # Точка входа сервера
├── internal/
│   ├── client/          # Клиентская бизнес-логика
│   ├── config/          # Конфигурация (env + viper)
│   ├── crypto/          # Шифрование данных
│   ├── grpc/            # gRPC-сервер и клиенты
│   ├── handler/         # Обработчики
│   ├── models/          # Общие модели и protobuf
│   ├── service/         # Бизнес-сервисы
│   ├── storage/         # PostgreSQL + миграции
│   ├── token/           # JWT-логика
│   └── tui/             # Терминальный интерфейс
├── proto/               # .proto файлы и сгенерированный код
├── migrations/          # Goose-миграции БД
├── pkg/                 # Переиспользуемые пакеты (при необходимости)
├── .env.example
├── secret.example.json
├── go.mod
└── README.md
```
**Быстрый старт**
1. Клонирование и подготовка
2. 
Bashgit clone https://github.com/aga-absolut/Vault-System.git

cd Vault-System

# Пример конфигурации
cp .env.example .env

cp secret.example.json secret.json

2. Запуск сервера
   
go run ./cmd/server/main.go -a :3200 -d "postgres://user:pass@localhost:5432/keeper?sslmode=disable"

4. Запуск клиента (TUI)

Bashgo run ./cmd/client/main.go

# Сервер
go build -o bin/gophkeeper-server ./cmd/server
